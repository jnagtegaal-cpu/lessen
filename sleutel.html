Je sleutel voor dit apparaat

Met je persoonlijke GitHub-sleutel kun je op dit apparaat lessen maken, aanpassen en verwijderen. Zonder sleutel kan iedereen de lessen alleen bekijken en geven. Collega's hebben dus geen sleutel nodig.

Zo maak je een sleutel (eenmalig)

  1. Ga naar github.com → nieuwe fine-grained sleutel (je moet ingelogd zijn).
  2. Token name: Lesbord. Expiration: kies bijvoorbeeld 1 jaar.
  3. Repository access: kies Only select repositories en selecteer lessen.
  4. Permissions → Repository permissions → Contents: zet op Read and write. De rest laat je staan.
  5. Klik onderaan op Generate token, kopieer de sleutel (begint met github_pat_) en plak hem hierboven.

De sleutel wordt alleen in deze browser op dit apparaat bewaard. Gebruik je een gedeeld schoolapparaat? Wis hem dan na gebruik, of maak een sleutel die maar kort geldig is. Kwijt of verlopen? Maak gewoon een nieuwe.
